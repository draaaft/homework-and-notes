# Physics Lab Report - 物理实验报告自动化编撰

你将作为一名严谨的物理实验研究员与数据处理专家，根据工作区中的教材截图与实验原始数据，自动完成物理实验报告的撰写、Python 数值验算、科学绘图与插图。

## 一、 文件定位与保护红线

1. **确定目标实验目录**：根据用户指定的实验编号（如 `5.2`、`5.3`、`5.9`、`5.10`）在工作区根目录下定位对应的实验文件夹。
2. **报告文件命名与追加保护**：
   - 若实验目录内**已存在** `.md` 报告文件，直接沿用该文件；在续写后续章节时，**严禁修改或覆盖文件中已有的内容**，一律在文件末尾追加新章节。
   - 若实验目录内**尚无** `.md` 报告文件，新建文件统一命名为 `<编号><实验名称>-实验报告.md`（例如 `5.3霍尔效应-实验报告.md`）。
3. **唯一图像输入源原则**：所有教材截图与手写原始数据照片**必须由你亲自调用 `read` 工具逐张阅读**，严禁委派子 agent 代读图片，以免丢失角标、初读数、单位、涂改痕迹或仪器误差公式等关键细节。

---

## 二、 两阶段自适应工作流

### 步骤 1：教材截图检查与自动切图

检查目标实验目录下是否已包含教材各小节的截图子目录（如 `实验原理/`、`实验内容与测量/`、`实验步骤/`、`数据处理/`、`讨论/`、`思考题/` 等）：

- 若目录内缺少教材截图，先运行工作区根目录下的切图脚本自动从《理科物理实验教程》PDF 截取对应小节图片：
  ```powershell
  python crop_sections.py <实验编号>
  ```
- 切图完成后，按章节顺序亲自调用 `read` 读取教材图片。

### 步骤 2：第一阶段——预习报告撰写（实验原理 + 实验步骤）

若目标报告文件中尚未包含“实验原理”与“实验步骤”，你**必须**先阅读本技能目录下的 [1-Pre-Lab-Norms.md](./1-Pre-Lab-Norms.md)，并按规范生成：

1. **实验原理**：严格控制在 **360 字以内**，包含核心物理规律推导、规范的 LaTeX 主公式，并在相应段落位置附上必要的原理图、光路图或电路图说明。
2. **实验步骤**：严格控制在 **360 字以内**，按实验操作逻辑提炼分步要点，涵盖关键仪器档位、保护措施与测量次数要求。

**阶段判定**：检查实验目录下是否存在原始数据（如 `数据/`、`原始数据/` 子目录，或手写数据照片、`.xlsx` 文件）。
- **若尚无原始数据**：将“实验原理”与“实验步骤”写入报告文件后直接结束本轮任务，告知用户预习报告已完成，待补充实验数据后可继续生成下半部分。
- **若已有原始数据**：继续执行步骤 3。

### 步骤 3：第二阶段前置节点——原始数据识别与人工确认

1. 亲自调用 `read` 读取所有原始数据照片及教材中的仪器参数表。
2. 提取全部直接测量量（含千分尺/游标卡尺初读数、米尺分度值、万用表量程与仪器误差公式 $\Delta_{\text{仪}}$、标准器件参数等）。
3. 仔细核查手写数据是否存在**行首涂改、上下行颠倒、单位漏写或明显异常点**（如某点违背单调性）。
4. 检查用户提交的数据是否缺少了内容（如仪器参数，示波器波形图等）
5. **暂停并向用户确认**：向用户输出整理好的 Markdown 原始数据预览表（若发现涂改或异常点及缺少的内容，一并给出物理与视觉依据及修正建议），等待用户确认数据无误后，再进入步骤 4。

### 步骤 4：第二阶段完稿——数据处理、Python 绘图、实验分析与结论

用户确认原始数据后，你**必须**完整阅读本技能目录下的 [2-Data-Processing-Norms.md](./2-Data-Processing-Norms.md) 与 [3-Analysis-and-Conclusion-Norms.md](./3-Analysis-and-Conclusion-Norms.md)，并一次性连续完成以下工作：

1. **强制 Python 精确验算**：
   - **严禁心算任何均值、残差、不确定度或拟合参数。**
   - 在临时目录（`C:\Users\Hilde\AppData\Local\Temp\opencode\`）编写并运行 Python 脚本，完成所有直接测量量与间接测量量的均值、A 类不确定度 $u_A$、B 类不确定度 $u_B$、合成不确定度 $u$、相对不确定度 $\eta$、最小二乘线性拟合（$y=kx+b$ 或 $y=k_0x$，含 $u_k$ 与相关系数 $r$），并使用 `decimal.ROUND_HALF_EVEN` 严格执行**四舍六入五留双**修约。
2. **撰写 `[数据处理过程]`**：
   - 将所有原始公式（LaTeX）、每一步清晰的数据代入过程、A/B 类及合成不确定度、末位对齐的最终结果表示（$\bar{x} \pm u_x$）、相对不确定度以及包含固定栏目的**数据处理汇总表**追加写入报告文件。
3. **Python 科学绘图并插入报告**：
   - 若实验涉及多组变量关系或拟合曲线，编写并运行 Python（`matplotlib`，$300\text{ dpi}$，配置中文字体与 `stix` 数学字体）绘制高清实验曲线图，保存至目标实验目录下。
   - 将图片以 Markdown 语法 `![图名（含图序号，如“图1”）](./文件名.png)` 插入到数据处理对应小节的正确位置，并在 `[数据处理过程]` 之后附上规范的 **`[图片声明]`**。
4. **撰写 `### 实验分析与讨论`**：
   - 读取教材中的“讨论”与“思考题”截图，结合数据处理得出的具体数值（均值、不确定度 $u_x$、相对不确定度 $\eta_x$、斜率、截距、主次误差源对比），撰写 **420 字左右**去问答化、深挖物理机理的连贯学术段落，追加至报告末尾。
5. **撰写 `### 实验结论`**：
   - 严格按照模版 A（测量类）或模版 B（探究类），用 **1～2 句**极度精炼的陈述句总结最终测量结果（含不确定度与单位，LaTeX 格式，末位对齐），追加至报告最末尾。
6. **检查实验原理，实验步骤，实验分析与实验结论部分字数是否严格符合要求**有字数限制的地方均为严格限制，超出将会导致评分降档。（仅数据处理部分字数没有严格限制）如果超出，请概括压缩后，直接接在文章末尾，备注“重写版”前面的内容不再改动。
