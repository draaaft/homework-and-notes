# 预习报告撰写规范（实验原理与实验步骤）

在撰写实验报告的“实验原理”与“实验步骤”部分时，必须先仔细阅读对应实验目录下的教材截图，并严格遵守以下规范：

## 一、 实验原理撰写规范

1. **字数限制**：严格控制在 **不超过 360 字**（含 LaTeX 公式实际内容字数（字母与数字），不含附图说明标记）。
2. **核心要素**：
   - **逻辑严密、内容完整**：提炼实验的核心物理机制、测量方法（如四端法、比较法、磁控管法、磁聚焦法、霍尔效应副效应消除法等）及关键近似条件。
   - **完备的物理公式**：必须使用规范的 LaTeX 格式（独立公式用 `$$...$$`，行内变量用 `$...$`）列出从基本物理定律到最终待测物理量工作表达式的关键推导公式，并简要说明各物理量符号的物理意义。
   - **必要的附图说明**：实验原理必须标明所需的原理图、光路图或电路图。在对应段落后使用如下规范格式标注附图位置与内容，：
     `*【附图1：xxx原理图/电路图/光路图（见图x.x-x）】*`
    并将图片保存在对应实验目录下，并用 Markdown 语法 `![图名](./文件名.png)` 直接插入到报告中对应计算小节的正确位置。
## 二、 实验步骤撰写规范

1. **字数限制**：严格控制在 **不超过 360 字**。
2. **核心要素**：
   - **分步编号、条理清晰**：按实际实验操作的先后逻辑（如：方案设计与仪器选型 $\to$ 几何量/静态参数校准与多次测量 $\to$ 电路/光路连接与安全初始状态设置 $\to$ 通电调节与数据测录 $\to$ 断电整理与数据计算核验）分条列出。
   - **关键操作细节不遗漏**

重申：字数限制是严格的，超限将会直接导致报告被扣分。
